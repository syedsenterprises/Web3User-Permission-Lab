Implemented Security & Durability Foundation

Hardware-Backed Cloud KMS/HSM Signing

Production signer adapters for AWS KMS and GCP Cloud KMS, with DER-to-raw RFC 8410 Ed25519 normalization, algorithm contract enforcement and factory resolution.

Deterministic Consensus State Reducer

Pure state machine reducer for distributed consensus log events: 11 action types, single-slot idempotency, atomic epoch transitions, strict monotonic index enforcement.

Multi-Process Race & Replay Prevention

Deterministic IPC rendezvous barriers release competing processes simultaneously to consume the same V3 authorization; tests enforce exactly one ALLOW and three domain-level DENY outcomes, with one persistent record.

Transaction Rollback & Contention Retries

Immediate SQLite write transactions (BEGIN IMMEDIATE;) roll back partial writes and clock updates on failure. Bounded retry loops with non-spinning sleep resolve transient contention or fail closed.

Authorization & Signing-Key Boundaries

Boundary tests enforce rejection at the exact expiration second (nowSeconds >= expiresAtSeconds), clip expiry to policy/key caps, and enforce key validity windows and post-retirement forgery rejection.

Monotonic Clock & Replay Protection

ClockGuard monotonic time anchoring prevents time-travel attacks. Clock high-water marks, policy revisions, key governance states and SQLite WAL schemas survive restarts without corruption.

      Architectural Boundary Notice

      What is running in your browser: Policy evaluation, budget checks, calldata decoding and rule checks — 100% client-side in pure JavaScript. No data leaves your browser.

      What requires Node.js runtime: Ed25519 signing, ClockGuard anchoring, persistent replay protection and atomic budget accumulators need the Node.js SDK (Web3UserEngine) with SQLite WAL mode. To test multi-process replay attacks on your machine, run npm run demo:persistent-replay.
